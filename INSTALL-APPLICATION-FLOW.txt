2. Decompresser cette archive dans C:\DevOps\applymatch-ai.
3. Accepter le remplacement des deux fichiers.
4. Relancer le backend :
   .\.venv\Scripts\Activate.ps1
   uvicorn app.main:app --reload
5. Dans un second terminal PowerShell, relancer le frontend :
   cd C:\DevOps\applymatch-ai\frontend
   npm run dev
6. Actualiser la page avec Ctrl+F5.
