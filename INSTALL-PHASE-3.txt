APPLYMATCH AI — INSTALLATION DE LA PHASE 3
==========================================

But : reconnaître les technologies connues, inconnues et obligatoires.
RapidFuzz est activé. spaCy est volontairement reporté à l'étape suivante.

IMPORTANT
---------
- Exécuter uniquement les commandes, sans copier « PS C:\...> ».
- Conserver la sauvegarde de phase 0.
- Lancer les commandes depuis C:\DevOps\applymatch-ai.

1. DÉCOMPRESSER L'ARCHIVE
-------------------------
Fermer les serveurs backend et frontend, puis exécuter dans PowerShell :

cd C:\DevOps\applymatch-ai
Expand-Archive -Path "$env:USERPROFILE\Downloads\applymatch-ai-phase-3.zip" -DestinationPath "C:\DevOps\applymatch-ai" -Force

Si le fichier a été téléchargé ailleurs, remplacer uniquement le chemin après -Path.

2. ACTIVER PYTHON 3.11 ET INSTALLER RAPIDFUZZ
----------------------------------------------
cd C:\DevOps\applymatch-ai
.\.venv\Scripts\Activate.ps1
python --version
python -m pip install -r requirements.txt

La version Python doit commencer par 3.11.

3. METTRE LA BASE À JOUR
------------------------
python -m alembic upgrade head
python -m alembic current

Résultat attendu : 8c42d1e7a5b9 (head)

4. TESTER LE BACKEND
--------------------
python -m pytest tests\test_technology_matcher.py -q
python -m pytest tests -q

Le premier test doit afficher 9 passed.
Le test complet doit finir sans FAILED.

5. TESTER LE FRONTEND
---------------------
cd C:\DevOps\applymatch-ai\frontend
npm test -- --run
npm run build

Les deux commandes doivent finir sans erreur.

6. RELANCER L'APPLICATION
-------------------------
Terminal backend :

cd C:\DevOps\applymatch-ai
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --reload

Terminal frontend :

cd C:\DevOps\applymatch-ai\frontend
npm run dev

7. VALIDER VISUELLEMENT
-----------------------
- Ouvrir une offre et relancer son analyse.
- Vérifier les sections :
  * Technologies connues et prouvées
  * Technologies inconnues
  * Technologies obligatoires
- Une technologie inconnue ne doit jamais être ajoutée au CV ou à la lettre.

REMARQUE SUR SPACY
-----------------
Ne pas installer spaCy maintenant. Il sera ajouté après validation de cette
phase déterministe afin de limiter les risques et de conserver une base stable.
