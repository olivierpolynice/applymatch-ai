APPLYMATCH AI — INSTALLATION DE LA PHASE 5
==========================================

But : collecter automatiquement France Travail et Adzuna toutes les 15
minutes, sans créer de doublons.

PRÉREQUIS
---------
- Les Phases 3 et 4 doivent déjà être installées.
- Conserver la sauvegarde de Phase 0.
- Ne jamais publier le fichier .env et ne jamais envoyer ses clés dans le chat.

1. DÉCOMPRESSER
---------------
Fermer les serveurs backend et frontend, puis exécuter dans PowerShell :

cd C:\DevOps\applymatch-ai
Expand-Archive -Path "$env:USERPROFILE\Downloads\applymatch-ai-phase-5.zip" -DestinationPath "C:\DevOps\applymatch-ai" -Force

2. INSTALLER APSCHEDULER
-----------------------
cd C:\DevOps\applymatch-ai
.\.venv\Scripts\Activate.ps1
python --version
python -m pip install -r requirements.txt

La version doit commencer par Python 3.11.
Aucune migration Alembic n'est nécessaire pour cette phase.

3. TESTER AVANT D'AJOUTER LES CLÉS
----------------------------------
python -m pytest tests\test_phase5_collection.py tests\test_external_collectors.py tests\test_offer_importer.py -q
python -m pytest tests -q

Résultat attendu : aucun FAILED.

4. OBTENIR LES IDENTIFIANTS FRANCE TRAVAIL
-------------------------------------------
1. Ouvrir https://francetravail.io
2. Créer un compte développeur.
3. Créer une application nommée « ApplyMatch AI ».
4. Ajouter l'API « Offres d'emploi v2 ».
5. Copier le Client ID et le Client Secret.

5. OBTENIR LES IDENTIFIANTS ADZUNA
----------------------------------
1. Ouvrir https://developer.adzuna.com/signup
2. Créer un compte développeur.
3. Créer l'application « ApplyMatch AI ».
4. Copier Application ID et Application Key.

6. CONFIGURER LE FICHIER .env
-----------------------------
Ne pas remplacer le fichier .env existant. L'ouvrir :

cd C:\DevOps\applymatch-ai
code .env

Ajouter ou modifier uniquement ces lignes avec les vraies valeurs :

FRANCE_TRAVAIL_CLIENT_ID=REMPLACER_ICI
FRANCE_TRAVAIL_CLIENT_SECRET=REMPLACER_ICI
ADZUNA_APP_ID=REMPLACER_ICI
ADZUNA_APP_KEY=REMPLACER_ICI
COLLECTOR_SCHEDULER_ENABLED=true
COLLECTOR_INTERVAL_MINUTES=15
COLLECTOR_RUN_ON_STARTUP=true

Enregistrer le fichier. Ne pas mettre de guillemets autour des valeurs.

7. DÉMARRER LA COLLECTE AUTOMATIQUE
-----------------------------------
cd C:\DevOps\applymatch-ai
.\.venv\Scripts\Activate.ps1
python -m uvicorn app.main:app --reload

La première collecte démarre au lancement, puis recommence toutes les 15
minutes. APScheduler empêche deux exécutions simultanées dans ce processus.

8. VÉRIFIER
-----------
Dans le frontend, vérifier :
- les nouvelles offres France Travail et Adzuna ;
- published_at, source_url et external_id ;
- l'absence de doublon après la deuxième collecte ;
- les offres déjà postulées restent dans « Déjà postulé » ;
- les nouvelles offres passent automatiquement dans le matching.

Pour arrêter temporairement la collecte, mettre dans .env :

COLLECTOR_SCHEDULER_ENABLED=false

Puis redémarrer le backend.
