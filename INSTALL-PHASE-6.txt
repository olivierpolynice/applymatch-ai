APPLYMATCH AI — INSTALLATION DE LA PHASE 6
==========================================

But : produire un CV adapté, une lettre Word, une lettre PDF et un message,
puis relire automatiquement les PDF avant utilisation.

PRÉREQUIS
---------
- Les Phases 3, 4 et 5 doivent déjà être installées.
- Conserver la sauvegarde de Phase 0.
- L'IA est désactivée par défaut : la génération Jinja2 fonctionne sans clé.

1. DÉCOMPRESSER
---------------
Fermer les serveurs, puis exécuter dans PowerShell :

cd C:\DevOps\applymatch-ai
Expand-Archive -Path "$env:USERPROFILE\Downloads\applymatch-ai-phase-6.zip" -DestinationPath "C:\DevOps\applymatch-ai" -Force

2. INSTALLER LE SOCLE WINDOWS
-----------------------------
cd C:\DevOps\applymatch-ai
.\.venv\Scripts\Activate.ps1
python --version
python -m pip install -r requirements.txt

Ce socle installe Jinja2, python-docx, ReportLab et PyMuPDF.
Aucune migration Alembic n'est nécessaire.

3. TESTER
---------
python -m pytest tests\test_phase6_generation.py tests\test_application_drafts.py -q
python -m pytest tests -q

Résultat attendu : aucun FAILED.

Puis tester le frontend :

cd C:\DevOps\applymatch-ai\frontend
npm test -- --run
npm run build

4. UTILISER LA GÉNÉRATION
-------------------------
1. Démarrer le backend et le frontend.
2. Approuver une offre dans « Validation humaine ».
3. Générer son brouillon.
4. Dans « Brouillons de candidature », relire et enregistrer les textes.
5. Cliquer sur « Générer CV, Word et PDF ».
6. Attendre « Documents générés et vérifiés automatiquement ».
7. Télécharger la lettre PDF, la lettre Word et le CV adapté PDF.

Les fichiers locaux sont rangés dans generated_documents/ et ignorés par Git.

5. WEASYPRINT — OPTIONNEL
-------------------------
ReportLab est le moteur PDF par défaut sous Windows. Pour essayer WeasyPrint :

cd C:\DevOps\applymatch-ai
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-weasyprint.txt

Puis ajouter dans .env :

PDF_ENGINE=weasyprint

Si WeasyPrint signale une dépendance système manquante, remettre :

PDF_ENGINE=reportlab

6. API D'IA — OPTIONNELLE ET DÉSACTIVÉE PAR DÉFAUT
--------------------------------------------------
La génération déterministe suffit pour valider cette phase. Pour une API
compatible avec le format Chat Completions, ajouter plus tard dans .env :

AI_TEXT_GENERATION_ENABLED=true
AI_API_URL=URL_COMPLETE_DU_POINT_DE_TERMINAISON
AI_API_KEY=VOTRE_CLE_PRIVEE
AI_MODEL=NOM_DU_MODELE

Ne jamais publier la clé. Le modèle reçoit uniquement l'offre, les données
autorisées du profil YAML, les projets prouvés, les technologies connues et les
modèles déterministes. Toute réponse invalide revient automatiquement à Jinja2.

Pour désactiver immédiatement l'IA :

AI_TEXT_GENERATION_ENABLED=false
