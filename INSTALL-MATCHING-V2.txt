APPLYMATCH AI - INSTALLATION DE L'ALGORITHME V2

1. Arrêter le backend et le frontend avec Ctrl+C.

2. Décompresser le ZIP dans :
   C:\DevOps\applymatch-ai
   Accepter le remplacement des fichiers.

3. Ouvrir PowerShell à la racine du projet :

   cd C:\DevOps\applymatch-ai
   .\.venv\Scripts\Activate.ps1
   python -m alembic upgrade head
   python -m pytest tests -q

4. Démarrer le backend :

   python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000 --env-file .env

5. Dans un second terminal, démarrer le frontend :

   cd C:\DevOps\applymatch-ai\frontend
   npm test
   npm run build
   npm run dev

6. Ouvrir : http://localhost:3000

IMPORTANT
- Aucun git push n'est nécessaire pour les tests locaux.
- Les anciennes offres doivent être analysées de nouveau afin d'appliquer V2.
- Un score >= 70 prépare une candidature prioritaire.
- L'envoi réel automatique exige un canal autorisé et une confirmation externe.
